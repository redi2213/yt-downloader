# YT Bridge

یک اپلیکیشن اندرویدی برای دانلود از یوتیوب (و منابع دیگر) بدون نیاز به سرور شخصی. تمام کارهای سنگین (دانلود، آپلود، میزبانی فایل) را GitHub Actions انجام می‌دهد؛ اپ فقط یک کلاینت سبک است که ورک‌فلوها را اجرا می‌کند و نتیجه را نشان می‌دهد.

## نحوه‌ی کارکرد

۱. یک لینک به اپ می‌دهید (ویدیو یا پلی‌لیست یوتیوب، یا هر منبع دیگری که پشتیبانی می‌شود)
۲. اپ یک ورک‌فلوی GitHub Actions در همین ریپازیتوری را اجرا می‌کند
۳. ورک‌فلو با yt-dlp فایل را دانلود کرده و به‌عنوان یک GitHub Release آپلود می‌کند
۴. اپ تا پایان اجرا صبر می‌کند و یک لینک دانلود مستقیم به شما می‌دهد

بدون بک‌اند، بدون هزینه‌ی هاستینگ، بدون نگه‌داری سرور — فقط با اکانت گیت‌هاب و دقیقه‌های رایگان Actions شما.

## قابلیت‌ها

- **دانلود از یوتیوب** — انتخاب کامل کیفیت، یا دانلود سریع با کیفیت‌های آماده (۳۶۰p/۴۸۰p/۷۲۰p/۱۰۸۰p/بهترین) با یک کلیک
- **پشتیبانی از پلی‌لیست** — دانلود کل یک پلی‌لیست با یک کیفیت مشخص، بدون سؤال برای هر ویدیو
- **استخراج فقط صدا (MP3)**
- **Download Anything** — مرکزی برای منابع دیگر (مدیافایر، تیک‌تاک و غیره) که قابل گسترش است؛ می‌توان منابع جدید را بدون نیاز به بیلد جدید اپ، فقط از طریق کانفیگ ریموت اضافه کرد
- **ورود با گیت‌هاب** از طریق Device Flow — استفاده از اکانت و محدودیت‌های شخصی خودتان، بدون توکن مشترک
- **تاریخچه‌ی ریلیزها** — مرور، تغییر نام، فشرده‌سازی، یا حذف دانلودهای قبلی
- **وضعیت GitHub Actions** — بررسی کارهای در حال اجرا یا اخیر و اجرای ورک‌فلوها مستقیم از داخل اپ

## راه‌اندازی

۱. این ریپازیتوری را fork یا clone کنید
۲. یک GitHub Personal Access Token بسازید (یا از طریق Device Flow داخل اپ وارد شوید) با دسترسی‌های `repo` و `workflow`
۳. با [Buildozer](https://buildozer.readthedocs.io/) اپ را بیلد کنید (`buildozer android debug`)
۴. APK را نصب کرده و در اولین اجرا توکن را وارد کنید (یا وارد شوید)

## تکنولوژی‌های استفاده‌شده

- **اپ**: پایتون + [Kivy](https://kivy.org/) (رابط کاربری اندروید)
- **بک‌اند**: GitHub Actions (Ubuntu runners) — بدون سرور
- **دانلودر**: [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- **میزبانی فایل**: GitHub Releases (حذف خودکار بعد از ۲ روز)

## نکات

- فایل‌ها به‌صورت خودکار بعد از ۲ روز از Releases پاک می‌شوند
- نسخه‌ی رایگان GitHub Actions تعداد job همزمان محدودی دارد — اپ به همین دلیل تعداد دانلود موازی را محدود می‌کند
