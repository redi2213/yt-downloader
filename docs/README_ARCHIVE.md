# YT Bridge

اپ اندروید (Python/Kivy) برای دانلود از یوتیوب و سایت‌های دیگر، **بدون سرور**. کارهای سنگین را GitHub Actions انجام می‌دهد و فایل‌ها در GitHub Releases ذخیره می‌شوند. اپ فقط ورک‌فلو را اجرا می‌کند، وضعیتش را دنبال می‌کند و لینک نتیجه را نشان می‌دهد. نسخه‌ی فعلی: بخوانید `version.txt`.

## روش کار
1. کاربر لینک یا تنظیمات را در اپ وارد می‌کند (یا لینک را از برنامه‌های دیگر Share می‌کند).
2. اپ ورک‌فلو را با `workflow_dispatch` اجرا می‌کند (با `job_id` یکتا برای پیدا کردن همان ران).
3. ورک‌فلو (yt-dlp و ابزارهای دیگر) فایل را دانلود می‌کند و در Release با تگ `run-<run_id>` می‌گذارد.
4. اپ لینک را می‌گیرد و فایل را می‌تواند مستقیم روی گوشی ذخیره کند.

## قابلیت‌ها
- **یوتیوب:** یک کادر هوشمند (ویدیو / پلی‌لیست / کانال)، انتخاب کیفیت، دانلود سریع، MP3، چند لینک هم‌زمان، انتخاب ویدیو از پلی‌لیست یا کانال، دانلود دسته‌ای (`download-batch.yml`)
- **Download Anything:** هر سایت با yt-dlp (گزینه‌ی Check formats، نسخه‌ی اجرا روی گوشی، پروکسی/v2ray)، آپارات، تلگرام، فیلیمو، گوگل پلی، گوگل درایو، اینستاگرام، آپلود از لینک مستقیم، لینک‌های سریال
- **Mornye:** دریافت و دانلود موسیقی lossless روی خود گوشی (با تگ و کاور FLAC)
- **Lab و پلاگین‌ها:** ابزارهای آزمایشی از برنچ `lab`، و پلاگین‌های نهایی از برنچ `config` که بدون بیلد جدید به Download Anything اضافه می‌شوند
- **Auto follow:** دنبال‌کردن خودکار کانال یوتیوب/آپارات (سریالی یا آخرین ویدیوها) با زمان‌بندی
- **آروان‌کلاد:** آپلود فایل‌های ریلیز یا لینک به باکت آروان، و مدیریت فایل‌ها (لیست، تغییر نام، حذف) از Release History
- **مدیریت اجراها:** مرور ران‌ها، Run again، لاگ و خطا (با راهنمای فارسی)، اعلان ntfy و اعلان اندروید، Health check، Site log، بررسی نسخه‌ی جدید
- **دانلود داخل اپ:** مدیر دانلود چندتکه‌ای با Pause/Resume، پوشه‌ی دلخواه، Open/Share
- **Release History:** صفحه‌بندی، تغییر نام، زیپ، حذف، تمدید زمان نگه‌داری فایل
- **اجرا روی گوشی (اختیاری):** لیست پلی‌لیست، کیفیت‌ها و خواندن صفحه‌ی سایت با yt-dlp داخل اپ
- **ظاهر:** فارسی/انگلیسی (RTL)، تم، رنگ، فونت و اندازه
- **به‌روزرسانی از داخل اپ:** آپدیت ریپو از زیپ یا فایل‌ها، بیلد APK، دانلود و نصب خودکار، بکاپ پروژه
- **ورود با GitHub:** Device Flow یا توکن شخصی

## معماری
```
screens/   رابط Kivy (navigator.py = کنترلر)
services/  منطق برنامه (thread پس‌زمینه، بدون Kivy)
api/       فراخوانی GitHub، سرویس‌های بیرونی و تنظیمات محلی
core/      ابزارهای خالص (config, models, i18n, download manager, plugin_loader, ...)
scripts/   اسکریپت‌های ورک‌فلوها (publish, auto_follow, arvan_tool, xray_setup, ...)
.github/workflows/   ورک‌فلوهای دانلود، Lab و نگهداری
```
جریان: `screens → services → api/github`. هیچ لایه‌ای زیر Navigator به Kivy Clock وابسته نیست.

## برنچ‌ها
- `main`: کد اپ و ورک‌فلوها
- `config`: تنظیمات ریموت بدون نیاز به بیلد جدید: `config.json` (دکمه‌ها و راهنمای خطا)، `follows.json` / `follow-state.json`، `ntfy.json`، `site-log.jsonl`، پوشه‌ی `plugins/`
- `lab`: ابزارهای آزمایشی (`lab/index.json`)
- `backup`: بکاپ‌های زیپ پروژه

## راه‌اندازی
1. ریپو را fork کنید.
2. Secretهای مخزن را بسازید (فقط برای ابزارهایی که استفاده می‌کنید):
   `YTDLP_COOKIES`، `FILIMO_AUTHV1`، `GPLAYDL_API_KEY`، `TDL_SESSION`، `COOKIES_TXT`، `PROXY`، `V2RAY_CONFIG`،
   آروان: `ARVAN_ACCESS_KEY`، `ARVAN_SECRET_KEY`، `ARVAN_BUCKET`، `ARVAN_ENDPOINT`،
   ساخت APK: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`
3. ورک‌فلو `build-apk.yml` را اجرا کنید (یا از Settings داخل اپ) و APK را از Release نصب کنید.
4. در اپ با GitHub وارد شوید یا توکن (دسترسی `repo` و `workflow`) را وارد کنید.

## نکات
- نسخه با هر بیلد موفق خودکار بالا می‌رود (`version.txt`).
- فایل‌های ریلیزهای `run-*` و `auto-*` بعد از ۷ روز خودکار پاک می‌شوند (از اپ می‌شود تمدید کرد). APK و بکاپ پاک نمی‌شوند.
- فایل بالای ۲ گیگابایت در Release جا نمی‌شود (در Auto follow به بخش‌های قابل‌پخش تقسیم می‌شود).
- جزئیات فنی بیشتر: `ARCHITECTURE.md` و `PROJECT_NOTES.md`
